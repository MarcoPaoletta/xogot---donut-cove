# Donut Cove

An intentionally empty Godot 4.7.2 project for an autonomous AI build recorded for Letta Corporation and Xogot (video 9: Xogot AI for Godot). Claude Fable 5.2, in the Claude desktop app on Windows, builds the whole game through Xogot's `xo` CLI and its godot-xo skill, with no MCP.

A cozy donut shop tycoon on a tiny pirate island: stack donuts on your back to serve the pirate crew, grow the kitchen with unlock pads, buy a ship, and sail around the island blasting kraken tentacles and sharks for loot. Every model is from free CC0 Quaternius packs (`assets/quaternius/`).

Start with `KICKOFF.md`. The build contract is `docs/Donut Cove - Build GDD.md`. Driving xo on Windows: `docs/context/xo-windows.md`. Private authoring skills are local tooling, excluded from Git; running the game does not require them.
